# DeepRare identical-case comparison protocol

## Status: NOT YET A MATCHED COMPARISON

RareGenXAI evaluated 178 eligible RareBench cases (LIRICAL 143, MME 11, HMS 24) in the successful workflow:
https://github.com/uday8116/RareGenXAI/actions/runs/43485509434

DeepRare published results on RareBench cohorts, but those are aggregate metrics for different inclusion sets. **Do not present them as matched case-level comparison results.**

DeepRare paper: https://www.nature.com/articles/s41586-025-10097-9

## What is required to complete a fair comparison

1. Obtain genuine DeepRare ranked disease predictions on the **exact 178** cases from the same RareBench CSV, without giving the gold diagnosis to DeepRare.
2. Use HPO terms only, or explicitly label a multimodal comparison and supply exactly equivalent information.
3. Normalize DeepRare disease identifiers to the same OMIM/ORPHA identifiers used in `data/external/rarebench_cases.csv`; document mapping and ambiguity.
4. Export CSV with columns `case_id,ranked_disease_ids`. All 178 case IDs must occur exactly once; each ranked list is semicolon-separated and ordered best-first.
5. Run the existing evaluator:
```bash
python -m src.evaluate_external --cases data/external/rarebench_cases.csv --deeprare data/external/deeprare_predictions.csv --methods tfidf logistic random_forest overlap
```
6. Verify case-level alignment, sample sizes, diagnosis coverage, and any exclusions. Compare Top-1, Top-5, MRR and per-cohort results. Preserve model version, date, prompt, temperature, retrieval configuration and provenance of outputs.

## Why published DeepRare metrics cannot substitute

The DeepRare paper reports RareBench cohort-level metrics on its own cohort denominators, not necessarily the same subset as RareGenXAI's 178 eligible cases. In particular, our filtered MME cohort has 11 cases versus 40 source cases. A difference in percentage is not evidence of one model's superiority on identical cases.

## Research conclusion so far

A **matched DeepRare comparison is pending** until authentic case-level DeepRare outputs are supplied or DeepRare is run on the 178 inputs. No DeepRare predictions or matched DeepRare scores have been generated by RareGenXAI. The comparison mechanism is implemented in `src/evaluate_external.py` and rejects unmatched case-ID sets.
